# Greenfield.Content.AIModels

On-device AI models the Greenfield app downloads on demand, published as release assets (one release per content version, e.g. `android-dev-v7`). The app finds them through the signed index in [Greenfield.Content.Index](https://github.com/SideQuestVR/Greenfield.Content.Index) and checks every file's sha256.
